📘 Hướng dẫn nén & upload file zip

🎬 Xem video minh hoạ trước khi thực hiện

1. Quy tắc đặt tên file zip

Định dạng: HoTen_CAT.zip — không dấu, không khoảng trắng.

Ví dụ: PhamDangQuang_CAT.zip

2. Quy tắc đặt tên file bên trong

Mỗi file evidence phải có dạng: email@heineken.com.<đuôi>

Ví dụ: buiminhhieu@heineken.com.png, abc@heineken.com.eml

3. Cấu trúc zip ĐÚNG vs SAI

✅ ĐÚNG
PhamDangQuang_CAT.zip
├─ a@heineken.com.png
├─ b@heineken.com.eml
└─ c@heineken.com.msg
❌ SAI (có folder lồng)
PhamDangQuang_CAT.zip
└─ PhamDangQuang_CAT/
   ├─ a@heineken.com.png
   └─ b@heineken.com.eml

4. Cách nén đúng theo hệ điều hành

🪟 Windows
  1. Mở thư mục chứa các file evidence.
  2. Bôi đen chọn các file (Ctrl+A nếu chỉ có file cần nén) — KHÔNG chọn folder cha.
  3. Chuột phải → Send to → Compressed (zipped) folder.
  4. Đổi tên file vừa tạo thành HoTen_CAT.zip.
🍎 macOS
  1. Bôi chọn các file evidence trong Finder (KHÔNG chọn folder).
  2. Chuột phải → Compress N items.
  3. Đổi Archive.zip thành HoTen_CAT.zip.

❗ Vì sao không được lồng folder?

Khi zip chứa folder con, hệ thống phải duyệt thêm cấu trúc lồng nhau, làm chậm quá trình upload và có thể gây trùng đường dẫn file. Vì vậy zip kiểu này sẽ bị từ chối.
