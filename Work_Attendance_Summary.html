⚙️ Thiết lập bảng Đơn Xin Nghỉ Phép

Tính năng đăng ký nghỉ phép cần bảng hr_leave_requests trong Supabase. Vào Supabase → SQL Editor và chạy lệnh sau:

click để copy CREATE TABLE hr_leave_requests (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  employee_id UUID REFERENCES hr_employees(id) ON DELETE CASCADE,
  employee_name TEXT,
  leave_date DATE NOT NULL,
  days_count NUMERIC NOT NULL DEFAULT 1,
  session_type TEXT,
  reason TEXT,
  status TEXT DEFAULT 'pending',
  created_at TIMESTAMPTZ DEFAULT NOW()
);

Sau khi tạo xong, tải lại trang này để kích hoạt tính năng.
